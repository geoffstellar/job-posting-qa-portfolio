Standard Check

Fetches all live job postings from Hireology, runs the full automated QA pipeline (rule-based checks + HTML/tone/boilerplate checks), and updates ticket history.

Use this for your regular daily or weekly sync. No AI costs — fully automated. 


  


  

    
AI Check

    
Runs a Standard Check first to get fresh data, then sends each unreviewed posting
       to Claude for deeper analysis: missing sections, tone issues, community name accuracy,
       compensation clarity, and other issues only a reader can catch. New findings are added
       as CLAUDE tickets — known types go live immediately, novel types go to Pending Review.
       Grammar and spelling issues are auto-approved and skip Pending Review.

    

      ⏱ Takes a few minutes depending on how many postings are queued.
      Keep this tab open until it finishes.
    

    

      
    

    

  


  

    
Ticket Controls

    
Checks are organized by Category (the single taxonomy axis):
       Tone, Content, Formatting, Structure, Job Title, HTML. Each check is tagged
       with an optional Section (display-only metadata that tells communities
       where in the posting the issue lives). Set the severity, toggle
       community-page visibility, choose how the check dedupes across sections,
       and edit the explanation shown to communities. Changes save automatically.
